JustHost 在英国提供 LON1 和 LON2 两个伦敦节点，后台支持一键切换数据中心和切换 IP。这一点是它相对同类商家的实际优势：换机房、换 IP 都不额外收费，而同类商家里换一次 IP 收 £5 的并不少见，所以拿它做多地区测试的成本很低。

## 国内访问：280 ms 的 ping 是怎么走出来的

机房在伦敦，不等于从国内连过去就近。三网去程路由的实测结果是：电信和联通都从广州出口，经美国圣何塞节点转到伦敦；移动从上海出口，经法兰克福转到伦敦。

延迟数据也吻合这个路径。全国三网平均 ping 在 280 ms 左右，电信和联通各约 261 ms，移动约 321 ms。海外节点之间稳定性不错，丢包少见；国内节点表现参差，取决于运营商。

这个成绩对建站够用，对交互式应用和游戏就偏高了。如果你的用户主要在欧洲或英国本地，这些数字跟你关系不大；如果你的用户和操作端都在国内，需要考虑中转，或者先想清楚 280 ms 会不会影响你的使用方式。
